# 1. Установка SSH-клиента и генерация ключевой пары
[x] Проверяю наличие SSH-клиента в системе выводом версии SSH
```
ssh -V
```
[x] Генерю новую пару ключей.
```
ssh-keygen -t ed25519
```
Перед генерацией утилита ssh-keygen предлагает задать пароль приватного ключа - не отказываюсь.

[x] Убеждаюсь, что публичный ключ корректен и на своём месте.
```
ssh-keyge -y -f ~/.ssh/id_ed25519
```
```
cat ~/.ssh/id_ed25519.pub
```

вывод в консоль: скриншот **1.png**


# 2. Добавление публичного ключа в аккаунт GitHub
[x] Копирую содержимое файла ~/.ssh/id_ed25519.pub в настройки аккаунта GitHub

см. скриншот **2.png**


# 3. Проверка SSH-подключения к GitHub
[x] Проверяю соединение с Гитхабом
```
ssh -T git@github.com
```
Вижу, что соединение устанавливается без пароля и возвращается приветствие от GitHub.

вывод в консоль: скриншот **3.png**


# 4. Работа с репозиторием по SSH
[x] Клонирую себе репозиторий
```
git clone git@github.com/brdwlt/thetaskisdone.git
```

вывод в консоль: скриншот **4.1.png**

[x] Коммичу, пушу
Для коммита создаю пустой файл и помечаю его как готовый к коммиту
```
touch test.txt && git add test.txt
```
Формирую коммит скомментарием
```
git commit -m "создан test.txt"
```
Выполняю push со стандартным именем в ветку main
```
git push origin master
```
Операция проходит с использованием ключа (пароль не просит)

вывод в консоль: скриншот **4.2.png**
